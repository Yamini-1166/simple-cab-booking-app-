🚖 Cab Booking App (Simple MERN Project)

📌 Project Overview
This is a Cab Booking Application built using the MERN stack (MongoDB, Express, React, Node.js).  
It is a simplified version of Uber/Ola where users can book rides, drivers can manage availability, and admins can view all rides.  
The project shows how a full‑stack app works with frontend + backend + database.

🎯 Features
- User:
  - Register and log in
  - Book a cab (pickup, drop, cab type)
  - View ride history
- Driver:
  - Register and log in
  - Mark availability
  - See assigned rides
- Admin:
  - View all rides
  - Manage users and drivers

⚙️ Technology Used
- Frontend → React  
- Backend → Node.js + Express  
- Database → MongoDB  

🛠️ How It Works
1. Login/Register → User or Driver creates an account.  
2. Book Ride → User enters pickup, drop, and cab type.  
3. Assign Driver → System assigns an available driver.  
4. Ride History → User can see past rides.  
5. Driver Dashboard → Driver can see rides assigned to them.  

🚀 Output (What You See)
- Login Page → Enter email & password.  
- Booking Page → Enter pickup & drop, choose cab type, click “Book”.  
- Ride History Page → Shows list of rides booked.  
- Driver Dashboard → Shows rides assigned to driver.  

📂 Project Structure
cab-booking-app/  
│── backend.js   # Backend server (Node.js + Express)

📝 Steps to Run
1. Run backend:  
   node backend.js  
2. Run frontend:  
   npm start  
3. Open browser → http://localhost:3000  

 ✅ Conclusion
This project is a mini cab booking system with all basic features (login, booking, ride history, driver dashboard).  
It is simple, lightweight, and perfect for quick submission.
